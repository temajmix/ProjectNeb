# ProjectNeb

Своя среда для Windows 11: панель, док, лаунчер и живые обои. Нативный Rust + Direct2D/D3D11, без .NET и без Chromium в постоянной памяти — в простое около 80 МБ на все компоненты вместо ~500 МБ у WebView2-аналогов.

**Скачать:** [Releases](../../releases/latest) — `ProjectNeb-0.1.0-beta-setup.exe` (установщик) или `ProjectNeb-0.1.0-beta-portable.zip` (портативная версия).

## Что умеет (0.1.0 Beta)

- **Панель сверху**: часы и дата, загрузка ЦП и ОЗУ, индикатор профиля.
- **Док**: закреплённые и запущенные приложения, индикатор запуска, переполнение «Ещё N», автоскрытие, виден поверх развёрнутых окон и прячется в полноэкранных приложениях.
- **Лаунчер**: `Alt+Space` (если занят — `Ctrl+Alt+Space`), поиск по ярлыкам меню «Пуск», `Enter` — запустить, `Esc` — закрыть.
- **Живые обои**: анимированная aurora за иконками рабочего стола (D3D11), пауза в полноэкранных приложениях и от батареи.
- **Супервизор**: поднимает компоненты при входе, перезапускает упавшее, восстанавливает скрытую панель задач после сбоя.

## Установка

1. Скачай установщик из Releases.
2. Запусти. Права администратора не нужны — ставится в `%LocalAppData%\ProjectNeb\app`.
3. Автозапуск — по желанию, галочка в установщике.

### SmartScreen: «Windows protected your PC»

Сборка пока без подписи, поэтому SmartScreen показывает предупреждение.

- Нажми **Подробнее → Выполнить в любом случае**.
- Либо сними блокировку заранее: правый клик по скачанному файлу → **Свойства** → галочка **Разблокировать** → **ОК**.
- Для портативной версии: разблокируй ZIP до распаковки — тогда предупреждение не появится ни у одного файла внутри.

Проект открытый, и мы подаём заявку на бесплатную подпись для open-source (SignPath / Certum OSS). Как только подпись появится, предупреждение уйдёт.

## Сборка из исходников

Нужны Rust 1.100 (GNU toolchain), MinGW-w64 (WinLibs) и Inno Setup 6 для установщика.

```
cd rust
cargo build --workspace --release
cargo test --workspace
```

Установщик: `installer/ProjectNeb.iss` → `ISCC.exe` при наличии собранных exe в `rust/target/release`.

## Настройки

Пока без окна настроек — файл `%LocalAppData%\ProjectNeb\config.json` (в портативной версии — `data\config.json`). После правки перезапусти ProjectNeb.

Полезные ключи: `shell.barEnabled`, `shell.dockEnabled`, `shell.dockAutoHide`, `shell.pinnedApps`, `wallpapers.enabled`, `wallpapers.pauseOnFullscreen`, `language` (`ru`/`en`).

## Требования

Windows 11 x64. Без установленного .NET и без Edge WebView2.

## Pro-подписка

В будущем появится Pro: облачная синхронизация настроек, магазин тем и сцен, автоматизация и ранний доступ. Подписка — это **сервис на нашей стороне**; проверка прав и выдача контента идут через сервер, поэтому подписку нельзя «включить» патчем клиента. Исходники при этом остаются открытыми — см. `docs/PRO.md`.
