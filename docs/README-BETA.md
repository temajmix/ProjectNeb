# ProjectNeb 0.1.0 Beta

![ProjectNeb](logo-mark.png)

Своя среда для Windows 11: панель, док, лаунчер и живые обои — одним установщиком, без .NET и без Chromium в постоянной памяти.

Это ранняя бета. Ставь на свой страх и риск, но она не меняет системные файлы, не требует прав администратора и удаляется одной кнопкой.

## Что внутри

- **Верхняя панель**: часы и дата, загрузка ЦП и ОЗУ, кнопка лаунчера, имя профиля.
- **Док**: закреплённые и запущенные приложения, индикатор запуска, переполнение («Ещё N»), автоскрытие.
- **Лаунчер**: `Alt+Space` — поиск по ярлыкам меню «Пуск», `↑`/`↓`, `Enter` — запуск, `Esc` — закрыть.
- **Живые обои**: анимированная aurora за иконками рабочего стола (D3D11), пауза в полноэкранных приложениях и от батареи.
- **Супервизор**: сам поднимает панель и обои, перезапускает упавшее, чинит скрытую панель задач после сбоя.

## Установка

1. Запусти `ProjectNeb-0.1.0-beta-setup.exe`.
2. SmartScreen скажет «неизвестный издатель» — это ожидаемо, подписи пока нет: «Подробнее» → «Выполнить в любом случае».
3. Галочка «Запускать при входе» — по желанию.
4. После установки откроется панель, док и обои.

Ставится в `%LocalAppData%\ProjectNeb\app`, права администратора не нужны.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `Alt+Space` | Лаунчер (если занят — `Ctrl+Alt+Space`) |
| `Enter` | Запустить выбранное |
| `Esc` | Закрыть лаунчер |

## Настройки

Пока без окна настроек — файл `%LocalAppData%\ProjectNeb\config.json`.

Частые вещи:

- `shell.barEnabled` — панель вкл/выкл.
- `shell.dockEnabled` — док вкл/выкл.
- `shell.dockAutoHide` — прятать док, когда мышь не у нижнего края.
- `shell.pinnedApps` — список путей к exe, например `"C:\\Windows\\System32\\notepad.exe"`.
- `wallpapers.enabled` — живые обои вкл/выкл.
- `wallpapers.pauseOnFullscreen`, `wallpapers.pauseOnBattery` — пауза.
- `language` — `"ru"` или `"en"`.

После правки перезапусти ProjectNeb (выйди из трея/диспетчера задач и запусти снова) — горячей перезагрузки настроек в бете нет.

Логи: `%LocalAppData%\ProjectNeb\logs\`.

## Память

Замеры на тестовой машине (1920×1080, Windows 11 26100):

| Компонент | Рабочий набор |
| --- | --- |
| панель + док | ~27 МБ |
| обои | ~41 МБ |
| супервизор | ~8 МБ |

Для сравнения: Electron/WebView2-подход на том же экране — ~500 МБ.

## Известные ограничения беты

- Окна настроек, тем и магазина пока нет — только JSON.
- Нет модулей zapret, Windhawk и Discord RP (они в следующих сборках).
- Проверено на одном мониторе; multi-monitor и смешанный DPI — в тестах, но не на живых экранах.
- Иконки 32×32, на 150 % могут выглядеть мягко.
- UWP-приложения не индексируются лаунчером (только ярлыки меню «Пуск»).
- Автозапуск добавляет запись в `HKCU\...\Run` — убирается при удалении.

## Удаление

Параметры → Приложения → ProjectNeb (Beta) → Удалить. Либо `%LocalAppData%\ProjectNeb\app\unins000.exe`.

Конфиг и логи остаются в `%LocalAppData%\ProjectNeb` — удали папку вручную, если не нужны.

## Приватность
