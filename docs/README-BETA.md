# ProjectNeb 0.3.0 Beta

![ProjectNeb](logo-mark.png)

Своя среда для Windows 11: панель, док, лаунчер и живые обои — одним установщиком, без .NET и без Chromium в постоянной памяти.

Это ранняя бета. Ставь на свой страх и риск, но она не меняет системные файлы, не требует прав администратора и удаляется одной кнопкой.

## Что внутри

- **Главное окно** — центр управления: статус, темы, виджеты, обои, обновления, сеть и доступ, Discord RP, замена Windows, Windhawk, логи.
- **Верхняя панель**: часы и дата, загрузка ЦП и ОЗУ, кнопка лаунчера, имя профиля.
- **Док**: закреплённые и запущенные приложения, индикатор запуска, переполнение («Ещё N»), автоскрытие.
- **Лаунчер**: `Alt+Space` — поиск по ярлыкам меню «Пуск», `↑`/`↓`, `Enter` — запуск, `Esc` — закрыть.
- **Живые обои**: анимированная aurora за иконками рабочего стола (D3D11), пауза в полноэкранных приложениях и от батареи.
- **Оконный менеджер**: раскладки Dwindle / MasterStack / Grid / Monocle, 4 рабочих пространства, правила, `Alt+стрелки`, `Alt+1..9`.
- **Обход блокировок**: импорт пака, 22 стратегии, самодиагностика, UAC-хелпер.
- **Discord RP**: пресеты, кнопки, правила «процесс → пресет».
- **Windhawk**: каталог модов, установка и удаление через Windhawk, состояние установленных модов.
- **Замена Windows**: обратимое скрытие панели задач, иконок, поиска, виджетов, Copilot.
- **Супервизор**: сам поднимает панель и обои, перезапускает упавшее, чинит скрытую панель задач после сбоя.

## Установка

1. Запусти `ProjectNeb-0.3.0-beta-setup.exe`.
2. SmartScreen скажет «неизвестный издатель» — это ожидаемо, подписи пока нет: «Подробнее» → «Выполнить в любом случае».
3. Галочка «Запускать при входе» — по желанию.
4. После установки откроется главное окно, панель, док и обои.

Ставится в `%LocalAppData%\ProjectNeb\app`, права администратора не нужны. Рядом с `neb-app.exe` лежит `WebView2Loader.dll` — без него окно настроек не запускается.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `Alt+Space` | Лаунчер (если занят — `Ctrl+Alt+Space`) |
| `Enter` | Запустить выбранное |
| `Esc` | Закрыть лаунчер |
| `Alt+стрелки`, `Alt+1..9` | Оконный менеджер: фокус и рабочие пространства |

## Настройки

Главное окно — `ProjectNeb.exe`; всё остальное читается из `%LocalAppData%\ProjectNeb\config.json`.

Частые вещи:

- `shell.barEnabled` — панель вкл/выкл.
- `shell.dockEnabled` — док вкл/выкл.
- `shell.dockAutoHide` — прятать док, когда мышь не у нижнего края.
- `shell.pinnedApps` — список путей к exe, например `"C:\\Windows\\System32\\notepad.exe"`.
- `wallpapers.enabled` — живые обои вкл/выкл.
- `wallpapers.pauseOnFullscreen`, `wallpapers.pauseOnBattery` — пауза.
- `language` — `"ru"` или `"en"`.
- `windowManager.enabled` — оконный менеджер.
- `discord.enabled` — Discord Rich Presence.
- `zapret.enabled` — обход блокировок.
- `windhawk.enabled` — интеграция с Windhawk.
- `updates.enabled` — проверять обновления вкл/выкл (по умолчанию вкл).
- `updates.manifestUrl` — адрес манифеста обновлений.
- `updates.checkHours` — как часто проверять, часы (1…168, по умолчанию 6).
- `updates.autoApply` — ставить скачанное обновление автоматически (по умолчанию вкл).

Модули (`windowManager`, `discord`, `zapret`, `windhawk`) выключены по умолчанию; включение добавляет их процессы-помощники. После правки перезапусти ProjectNeb (выйди из трея и запусти снова) — горячей перезагрузки настроек в бете нет.

Логи: `%LocalAppData%\ProjectNeb\logs\`.

## Обновления

Супервизор проверяет `latest.json`, скачивает portable-архив, сверяет SHA-256, складывает файлы в `%LocalAppData%\ProjectNeb\updates\<версия>` и передаёт замену `neb-updater.exe`. Тот ждёт выхода ProjectNeb, копирует файлы и запускает новую версию; после первого запуска показывается окно «Что нового». Ошибки проверки и загрузки пишутся в лог, установка при них не меняется.

## Память

Замеры на тестовой машине (1920×1080, Windows 11, 100 %):

| Компонент | Рабочий набор |
| --- | --- |
| панель + док | ~28 МБ |
| обои | ~42 МБ |
| супервизор | ~11 МБ |

Окно настроек на WebView2 живёт только пока открыто и закрывается вместе с ним; в простое его процессов нет. Для сравнения: Electron/WebView2-подход на том же экране — ~500 МБ.

## Известные ограничения беты

- Часть экранов настроек читает значения только при открытии (без live-обновления).
- После обновления окно «Что нового» модальное: пока его не закрыть, супервизор ждёт и не реагирует на «Выход».
- Проверено на одном мониторе; multi-monitor и смешанный DPI — в тестах, но не на живых экранах.
- Иконки 32×32, на 150 % могут выглядеть мягко.
- UWP-приложения не индексируются лаунчером (только ярлыки меню «Пуск»).
- Автозапуск добавляет запись в `HKCU\...\Run` — убирается при удалении.
- Установщик без подписи: SmartScreen покажет «неизвестный издатель».

## Удаление

Параметры → Приложения → ProjectNeb (Beta) → Удалить. Либо `%LocalAppData%\ProjectNeb\app\unins000.exe`.

Конфиг и логи остаются в `%LocalAppData%\ProjectNeb` — удали папку вручную, если не нужны.

## Приватность

Телеметрии нет. Сеть используется только для проверки обновлений и каталога Windhawk; Discord RP подключается к уже запущенному Discord. Остальное лежит локально.
